The Router Confesses — one line in which a home Wi-Fi router excuses itself for dying at the climax of a movie.

## The entry

> I did not drop your Wi-Fi at the climax; I simply refused to watch another hero survive something I would never survive.

120 characters, one line, plain ASCII — inside the 1–200 character gate.

## Why this line

Written against the judge's brief, in the order it weighs things:

1. **On subject** — a one-line excuse from a home Wi-Fi router for dropping the connection at a movie's climax.
2. **Funniest turn** — the router is not apologising for a fault, it is admitting a motive: it refused to watch another hero survive something it would never survive.
3. **The router's own voice** — petty, dramatic, a little smug, an appliance with a grudge rather than a generic apology.
4. **Lands in one breath** — a single line that reads clean, no setup that needs explaining.
5. **Feels new** — it dodges the obvious buffering, bandwidth and firmware-update jokes everyone has already heard.
